## Installation

Install the Mugon CLI on your system using one of the commands below.

Shell (Mac, Linux):
```sh
curl -fsSL https://mugon.net/install.sh | sh
```

PowerShell (Windows):
```powershell
irm https://mugon.net/install.ps1 | iex
```
